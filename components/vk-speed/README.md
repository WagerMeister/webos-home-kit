# VK ×2

Независимый плеер для выбранного в магазинном VK видео. Оригинальное приложение не модифицируется.

`launcher` и `service` открывают сессию; `runtime/capture.py` наблюдает активный медиапоток VK. Runtime проверяет источник и срок его снимка, запускает private CBE-плеер, обслуживает HLS bridge и управление пультом. `native` содержит metadata и отдельный input shim.

Поддерживаются HLS и прямые MP4 с MIME/ftyp-проверкой, скорость до 2×, качество 144p–4K/авто и переход ко времени. Обратной записи позиции в VK нет. Сессии и временные файлы не используются компонентом Kick.
