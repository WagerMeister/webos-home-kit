# Emoji font

Noto Emoji, Copyright2013 Google LLC, [SIL OFL1.1](OFL.txt). The bundled regular-weight WOFF2 supplies missing emoji glyphs while leaving ordinary text spacing unchanged. Native color emoji take precedence. The font is scoped to title symbols and isolated keycap sequences.

Source: [google/fonts, pinned revision](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoemoji). The variable font is instantiated at weight400 and converted with fontTools to WOFF2. No font download is required at runtime; changing the font requires updating its integrity assertion in test.cjs.
