# VPN

Независимый сервис управления VPN-клиентами и переключатель Hearth.

- `root/manager.js` — общий протокол, упорядочивание команд, безопасный выбор адаптера и состояние управления.
- `root/providers` — реализации движков и их явный реестр.
- `root/control.js` — локальный клиент контроллера; его команды не зависят от движка.
- `hearth-ui` — переключатель, статус и окно интерактивного входа.
