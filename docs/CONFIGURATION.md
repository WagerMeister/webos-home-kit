# Настройка

## Hearth и виджеты

Предпочтения Hearth хранятся в localStorage приложения, ключ `customlauncher-config-v1`. [settings/hearth.example.json](../settings/hearth.example.json) — preset первого запуска. Существующие настройки сохраняются; приложения и их порядок определяются установленным launcher.

Часы используют время и часовой пояс телевизора. Календарь выделяет текущий день. Погода по умолчанию выключена: выберите город в настройках Hearth, включите виджет и при необходимости отображение названия города. Поле `weather.city` содержит имя, широту и долготу выбранного места; координаты не определяются автоматически. Прогноз MET Norway включает три дня, ветер и осадки.

Сезонные сцены включены при `background="theme"`, `wallpaper.mode="gradient"` и `wallpaper.path="/media/developer/wallpapers/seasonal-scenes"`. Выбор фона использует локальные дату/время. При заданных координатах освещение рассчитывается по положению солнца, сезон учитывает полушарие; без координат используются местные часы. Необязательное поле `scenery.seasonByMonth` задаёт 12 названий сезонов по порядку месяцев для местного климатического календаря; без него используется календарь полушария. Свои изображения можно заменить в `dashboard/scenes/<season>/<phase>.jpg`, сохраняя имена четырёх сезонов и dawn/day/evening/night.

## VPN

Локальный config.json содержит `version`, `provider`, `enabled` и `providerConfig`. `provider` выбирает адаптер из реестра, а `providerConfig` содержит только его параметры. Параметры адаптера задаются по [примеру конфигурации](../components/vpn/config.example.json). Авторизация хранится на устройстве.

На Home: ↑ из первого ряда переводит фокус на «VPN», OK переключает состояние, ↓ возвращает в приложения. Статус включения появляется после проверки соединения, а не только после отправки команды. Способ входа определяется возможностями адаптера: при поддержке интерактивного входа интерфейс показывает QR, иначе используется заранее подготовленный локальный профиль.

В настройках Hearth, раздел System → «VPN — движок», доступен список установленных клиентов с подготовленными локальными профилями. Перед сменой движка выключите VPN. Переключатель действует на весь трафик ТВ.

Параметры текущего адаптера и порядок замены движка описаны в [руководстве адаптеров](../components/vpn/ADAPTERS.md). Существующая плоская конфигурация без `provider` читается как Tailscale; автоматического переноса авторизации между клиентами нет.

## Воспроизведение

**Kick:** выберите онлайн-канал или запись в самом клиенте. Скорость записи выбирается в плеере; ускоренный просмотр открывается в отдельном native-контуре. Стрелка вниз показывает управление; Back закрывает панель или возвращает к записям.

**VK ×2:** откройте ролик в обычном VK, затем Home→VK×2→OK. В плеере доступны скорость, качество и popup перехода ко времени, управляемый стрелками. Список качества содержит 144p–4K и авто; при отсутствии точного варианта выбирается доступный поток. Новая позиция из VK×2 в оригинальный VK не синхронизируется.

Настройки приложений, авторизация и состояние клиентов хранятся на устройстве.
